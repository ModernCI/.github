---

- **Fastest path from push to landed.** A merge queue with batching and bisect that also runs the checks, so it can reuse exact results and pick the tests that matter.
- **Your compute.** Any machine becomes a runner with `mci runner up`, and `mci run <command>` runs anything on demand.
- **Built for agents.** Agents connect over MCP, get reds pushed to them, and their fixes are verified before anything lands.
- **Build, sign, release.** Signing and provenance built in, publishing to every package channel.
- **Every PR shows a receipt** of what it cost and what it saved.

ModernCI is in early access. This GitHub organisation hosts distribution only (the Homebrew tap, the setup action and the GitHub App). Development happens elsewhere.
